Banco compartilhado automático

Na V10, todos os aparelhos usam a mesma base no Supabase. Não há login. Ao abrir a página, os dados são carregados automaticamente; ao alterar algo, a mudança é enviada para a nuvem e os outros aparelhos recebem a atualização.

Dados compartilhados atualizados Última sincronização: 07/08/2026, 14:00:22

Conexão do site

Use apenas a Publishable key (sb_publishable_...) ou a anon key pública. Nunca use service_role ou secret key. Depois de confirmar que funciona, use o botão abaixo para gerar um HTML já configurado para publicar no Render/GitHub.

Operação automática

Inicializar nuvem é usado apenas uma vez, no aparelho que contém os dados corretos, se o banco online ainda estiver vazio. Depois disso, a sincronização é automática.
Atenção: esta versão é compartilhada sem login. Quem tiver acesso ao endereço do site poderá visualizar e alterar os dados do painel. Não publique a service_role key.

Backup local

O banco online melhora a sincronização, mas o backup em arquivo continua recomendado antes de mudanças importantes.

Fotos novas

Publicação

O site principal está no Render. A galeria funciona separadamente pelo Google Apps Script e é exibida dentro da aba Fotos.

Dados do painel

Checklists, estoque e banco de preços usam o Supabase como base central compartilhada. O navegador mantém uma cópia local de contingência e a aba Backup permite exportar tudo em arquivo.

Diagnóstico rápido

  1. Abra a URL da galeria separadamente.
  2. Confirme se as fotos aparecem.
  3. Verifique se a URL termina em /exec.
  4. Atualize a implantação do Apps Script após alterar o código.
